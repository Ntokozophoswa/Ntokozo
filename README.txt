PUBLISHING THE WEBSITE PUBLICLY
This package is ready for static hosting. It is not public until it is uploaded to a hosting provider.

GitHub Pages quick steps:
1. Sign in to GitHub and create a new public repository (for example: ntokozo-phoswa-portfolio).
2. Upload index.html and README.txt. The portrait is embedded in index.html, so no image path is required.
3. Open the repository Settings, then Pages.
4. Under Build and deployment, select Deploy from a branch; choose the main branch and /(root), then Save.
5. Wait for GitHub Pages to publish and copy the public URL shown in Settings > Pages.

The public URL cannot be activated from this package alone; publishing requires signing into a hosting account and completing the steps above.
